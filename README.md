# DietiEstates25 - Your Real Estate Partner

This is the Repository for the Ingegneria del Software Project "DietiEstates25".

## Description

DietiEstates25 is a web application that allows users to search for and manage real estate properties. It provides a user-friendly interface for users to browse properties, view property details, contact agents and leave reviews. 
The application also includes a dashboard for agents and agency managers to manage their properties and and agencies.
